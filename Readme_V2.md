# Онлайн библиотека (OnlineLibrary)

Десктопное приложение «Онлайн библиотека» для управления каталогом книг, пользовательскими списками чтения, системой отзывов и модерации контента. Разработано в рамках учебной практики по ПМ.01 «Разработка модулей программного обеспечения для компьютерных систем».

**Репозиторий:** https://github.com/Zdeviant00/2ozISIP1624_Mizin_UP

---

## 📖 Инструкция по запуску

### Требования
- Visual Studio 2019/2022
- SQL Server 2019/2022 (Express или выше)
- SQL Server Management Studio (SSMS)

### Установка

**1. Создание базы данных**
1. Откройте SQL Server Management Studio
2. Подключитесь к серверу (обычно `.\SQLEXPRESS`)
3. Откройте файл `02_WPF_App/Database/OnlineLibrary.sql`
4. Выполните скрипт (F5)

**2. Настройка подключения**
1. Откройте проект в Visual Studio
2. Откройте файл `App.config`
3. Найдите строку подключения `OnlineLibraryEntities`
4. Измените `data source=.\SQLEXPRESS` на имя вашего сервера
5. Сохраните файл

**3. Запуск приложения**
1. Нажмите F5 в Visual Studio
2. Войдите в систему:
   - Администратор: логин `admin`, пароль `123456`
   - Пользователь: логин `reader1`, пароль `123456`

### Учётные данные

| Роль | Логин | Пароль |
|------|-------|--------|
| Администратор | admin | 123456 |
| Пользователь | reader1 | 123456 |
| Пользователь | reader2 | 123456 |
| Пользователь (заморожен) | reader3 | 123456 |
| Пользователь | reader4 | 123456 |

### Примечание о безопасности
Пароли хранятся в открытом виде (plain text) для упрощения демонстрации прототипа приложения.

## 🖥️ Раздел 1. Разработка WPF-приложения

### 1.1. Общее описание реализации

Разработано графическое десктопное приложение «Онлайн библиотека» с использованием интерфейса WPF (.NET Framework 4.8) на языке C#. Приложение реализует каталог книг, систему отзывов с оценками, личные списки чтения, модерацию контента (жалобы, заморозка) и административную панель.

**Технологии и инструменты:**
- **Язык программирования:** C#
- **Интерфейс:** WPF (Windows Presentation Foundation)
- **Платформа:** .NET Framework 4.8
- **Среда разработки:** Visual Studio 2026
- **База данных:** SQL Server 2022
- **ORM:** ADO.NET Entity Framework 6.x (Database First)
- **Паттерн проектирования:** Singleton (для контекста БД)

**Реализованный функционал:**
- ✅ Авторизация и регистрация пользователей
- ✅ Каталог книг с поиском, сортировкой и фильтрацией
- ✅ Страница книги с отзывами и оценками
- ✅ Личные списки книг («Читаю», «В планах», «Прочитано», «Заброшено»)
- ✅ Профиль пользователя с историей отзывов
- ✅ Система жалоб на книги и отзывы
- ✅ Модерация: заморозка/разморозка книг, отзывов, аккаунтов
- ✅ Административная панель с управлением пользователями

---

### 1.2. Анализ предметной области

Предметная область — «Онлайн библиотека», система для управления каталогом книг и взаимодействия читателей. Ключевые сущности:

- **Пользователи** (Users) — с ролями «Пользователь» и «Администратор»
- **Книги** (Books) — с жанрами, рейтингом, описанием
- **Отзывы** (Reviews) — с оценкой от 1 до 5
- **Списки книг** (BookLists, BookListItems) — личные коллекции пользователя
- **Жалобы** (Complaints) — на книги и отзывы
- **Заявки на разморозку** (FreezeRequests)

Система поддерживает механизм модерации: администратор может замораживать книги, отзывы и аккаунты пользователей. Замороженные пользователи могут оспорить заморозку через заявку.

### 1.5. Реализация логики приложения

#### 1.5.1. Паттерн Singleton для работы с базой данных

Для обеспечения единственной точки доступа к базе данных в файле `Model.Context.cs` реализован паттерн проектирования Singleton.

Во всех страницах приложения (`*.xaml.cs`) контекст базы данных получается через вызов `OnlineLibraryEntities.GetContext()`, что исключает создание множественных экземпляров и обеспечивает корректную работу с данными.

#### 1.5.2. Логика работы страниц

Для каждой страницы приложения в файле `*.xaml.cs` реализованы:
- **Конструктор класса** — инициализация компонентов, получение контекста БД, загрузка данных
- **Методы-обработчики событий** — обработка нажатий кнопок (атрибут `Click`), изменений в ComboBox, ввода текста
- **Методы загрузки данных** — загрузка книг, отзывов, списков из БД с использованием Entity Framework
- **Методы валидации** — проверка введённых данных перед сохранением

Все методы имеют XML-комментарии (`<summary>`, `<param>`) для документирования кода.

 *

 * - Меню для работы с каталогом книг
 * - Поиск книги по названию
 * - Вывод информации о книге на второй буфер экрана

#include <windows.h>

    return catalog;
}

// ============================================================================
// Функции работы с каталогом

/**
 * @brief Поиск книги по названию.
 * @param catalog Каталог книг.
 * @param searchQuery Строка поиска.
 * @return Указатель на найденную книгу или nullptr, если не найдена.
 */
const Book* searchBookByTitle(const vector<Book>& catalog, const string& searchQuery) {
    for (const auto& book : catalog) {
        if (book.title.find(searchQuery) != string::npos) {
            return &book;
        }
    }
    return nullptr;
}

// Функции работы с буфером экрана

/**
 * @brief Получение информации о текущем буфере экрана.
 * @param hConsoleHandle Дескриптор буфера экрана.
 */
void displayBufferInfo(HANDLE hConsoleHandle) {
    CONSOLE_SCREEN_BUFFER_INFO csbi;

    if (GetConsoleScreenBufferInfo(hConsoleHandle, &csbi)) {
        cout << "Информация о буфере экрана:" << endl;
        cout << "----------------------------------------" << endl;
        cout << "Размер буфера: " << csbi.dwSize.X << " x " << csbi.dwSize.Y << endl;
        cout << "Размер окна: " << csbi.srWindow.Right - csbi.srWindow.Left + 1
            << " x " << csbi.srWindow.Bottom - csbi.srWindow.Top + 1 << endl;
        cout << "Позиция курсора: (" << csbi.dwCursorPosition.X << ", " << csbi.dwCursorPosition.Y << ")" << endl;
        cout << "Атрибуты: " << csbi.wAttributes << endl;
        cout << "----------------------------------------" << endl;
    }
    else {
        cout << "Ошибка получения информации о буфере экрана!" << endl;
    }
}

/**
 * @brief Установка новых размеров буфера экрана.
 * @param hConsoleHandle Дескриптор буфера экрана.
 * @param width Новая ширина буфера.
 * @param height Новая высота буфера.
 * @return true, если размеры успешно изменены; false в противном случае.
 */
bool setBufferSize(HANDLE hConsoleHandle, int width, int height) {
    COORD newSize;
    newSize.X = width;
    newSize.Y = height;

    if (SetConsoleScreenBufferSize(hConsoleHandle, newSize)) {
        cout << "Размеры буфера экрана изменены на: " << width << " x " << height << endl;
        return true;
    }
    else {
        cout << "Ошибка изменения размеров буфера экрана!" << endl;
        return false;
    }
}

/**
 * @brief Вывод информации о книге на второй буфер экрана.
 * @param hBufferHandle Дескриптор второго буфера экрана.
 * @param book Указатель на книгу.
 */
void displayBookOnBuffer(HANDLE hBufferHandle, const Book* book) {
    if (book == nullptr) {
        string errorMsg = "Книга не найдена!\n";
        WriteConsoleA(hBufferHandle, errorMsg.c_str(), static_cast<DWORD>(errorMsg.length()), nullptr, nullptr);
        return;
    }

    string output = "========================================\n";
    output += "Информация о книге (вывод на второй буфер):\n";
    output += "========================================\n";
    output += "ID: " + to_string(book->id) + "\n";
    output += "Название: " + book->title + "\n";
    output += "Автор: " + book->author + "\n";
    output += "Жанр: " + book->genre + "\n";
    output += "Год издания: " + to_string(book->year) + "\n";
    output += "Рейтинг: " + to_string(book->rating) + " / 5.0\n";
    output += "========================================\n";
    output += "Нажмите любую клавишу для возврата...\n";

    WriteConsoleA(hBufferHandle, output.c_str(), static_cast<DWORD>(output.length()), nullptr, nullptr);
}

/**
 * @brief Точка входа в приложение.
 * @return Код завершения программы.
 */
int main() {
    SetConsoleCP(1251);
    SetConsoleOutputCP(1251);
    setlocale(LC_ALL, "Russian");

    vector<Book> catalog = initializeCatalog();

    HANDLE hStandardBuffer = GetStdHandle(STD_OUTPUT_HANDLE);

    HANDLE hSecondBuffer = CreateConsoleScreenBuffer(
        GENERIC_READ | GENERIC_WRITE,
        FILE_SHARE_READ | FILE_SHARE_WRITE,
        nullptr,
        CONSOLE_TEXTMODE_BUFFER,
        nullptr
    );

    if (hSecondBuffer == INVALID_HANDLE_VALUE) {
        cout << "Ошибка создания второго буфера экрана!" << endl;
        return 1;
    }

    cout << "Второй буфер экрана успешно создан!" << endl;

    int choice;
    bool running = true;

    while (running) {
        displayMainMenu();
        cin >> choice;
        cin.ignore();

        switch (choice) {
        case 1: {
            cout << "\nВведите название книги для поиска: ";
            string searchQuery;
            getline(cin, searchQuery);

            const Book* foundBook = searchBookByTitle(catalog, searchQuery);

            if (foundBook != nullptr) {
                cout << "\nКнига найдена! Вывод информации на второй буфер экрана..." << endl;

                if (SetConsoleActiveScreenBuffer(hSecondBuffer)) {
                    displayBookOnBuffer(hSecondBuffer, foundBook);
                    system("pause");
                    SetConsoleActiveScreenBuffer(hStandardBuffer);
                }
                else {
                    cout << "Ошибка активации второго буфера экрана!" << endl;
                }
            }
            else {
                cout << "\nКнига \"" << searchQuery << "\" не найдена в каталоге." << endl;
            }
            break;
        }

        case 2: {
            displayCatalog(catalog);
            break;
        }

        case 3: {
            cout << "\n--- Стандартный буфер экрана ---" << endl;
            displayBufferInfo(hStandardBuffer);

            cout << "\n--- Второй буфер экрана ---" << endl;
            displayBufferInfo(hSecondBuffer);
            break;
        }

        case 4: {
            int width, height;
            cout << "\nВведите новую ширину буфера (например, 120): ";
            cin >> width;
            cout << "Введите новую высоту буфера (например, 30): ";
            cin >> height;

            cout << "\nИзменение размеров стандартного буфера:" << endl;
            setBufferSize(hStandardBuffer, width, height);

            cout << "\nИзменение размеров второго буфера:" << endl;
            setBufferSize(hSecondBuffer, width, height);
            break;
        }

        case 0: {
            cout << "\nВыход из приложения..." << endl;
            running = false;
            break;
        }

        default: {
            cout << "\nНеверный выбор! Пожалуйста, выберите действие от 0 до 4." << endl;
            break;
        }
        }
    }

    CloseHandle(hSecondBuffer);

    cout << "\nПриложение завершено. До свидания!" << endl;

    return 0;
}
